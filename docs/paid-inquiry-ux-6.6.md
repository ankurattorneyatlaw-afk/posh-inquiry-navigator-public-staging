# Paid inquiry usability release 6.6

The inquiry screen now prioritises the current question, relevant drafts and dates. Detailed legal guidance, download references and advanced recovery tools remain available in collapsed sections. Stage prompts and document titles wrap fully, with consistent spacing from mobile to desktop.

Oral intake does not request a written-receipt date before writing assistance is complete. Future event prompts follow the current stage; urgent and overdue items remain visible across stages, with an all-records review available. Editing an earlier event preserves its original event type. Changing a procedural answer clears the prior draft download message. A blocked pre-inquiry draft offers a tracked follow-up rather than a blank stop.

Validation uses synthetic procedural selections and accounts: 51 stages and 165 answer branches at 320, 768 and 1440 pixels, oral-to-written document progression, blocked-draft follow-up, event relevance and edit integrity. Supporting checks cover document progression, paid lifecycle/recovery/renewal, local file updates and 58 accessibility states. Build and statutory timeline/document tests are required before release.

No statutory date arithmetic, authentication permissions, payment mode or case-storage policy is changed. No case details are included. Browser checks are not independent legal, security or accessibility certification.
