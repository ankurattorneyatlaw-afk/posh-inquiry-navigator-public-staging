# Focused guided workflow

The current question and contextual document remain primary. Timeline entry, legal guidance and the full document catalogue are collapsed by default. Earlier document steps can be reopened for correction and redownload; correcting upstream answers still invalidates dependent answers.

Only stage-relevant milestone choices and event kinds are offered by default. Central Rule 7 working-calendar controls appear only when those rules are selected as applicable and relevant. Conciliation safeguards do not appear in the ordinary inquiry forms. All prior controls remain accessible through an explicit review-all switch. View changes never alter route, actual dates or statutory calculations. Final completion still evaluates the entire saved record, including missing earlier dates and unresolved follow-ups. Urgent/overdue alerts remain visible across steps.

Routine blank document downloads no longer require a reviewer reference or explanation. A missing optional reference is logged locally as an unidentified session user, never as verified Committee approval. Timeline edits still require a reviewer reference and reason. The Word draft text and legal engine are unchanged in this release. Downloading remains distinct from issue, service, attendance or procedural completion.

Verification covers desktop/mobile focused controls, overdue preservation, working-calendar relevance, conciliation/inquiry separation, reopening earlier steps, A01–A04 progression, oral/unwritten assistance, witness/production notices and owned follow-ups, plus existing timeline and document unit tests.
